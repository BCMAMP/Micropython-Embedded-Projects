A simulation of a 2-axis pan-tilt gimbal control system using a Raspberry Pi Pico integrated with an OLED display and an analog joystick.

When the analog joystick is moved, the servo motors adjust their angles according to the joystick's direction, and the current angle is shown on the OLED display.
Pressing the analog joystick locks the servo angles, preventing further movement. The display indicates the lock status. To return to live control mode, the analog joystick must be pressed again.

component :
1. Analog Joystick (Input)
2. Servo ( Output / Aktuator )
3. OLED Display ( Output)
