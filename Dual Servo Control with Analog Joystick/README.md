A dual-servo motor motion control system based on analog joystick input and a buzzer alarm, utilizing the Raspberry Pi Pico.

In this system, the servos follow the direction of the analog joystick when it is moved, and the buzzer sounds when the joystick is pressed.

component :
1. Servo
2. Buzzer 
3. Analog Joystick
