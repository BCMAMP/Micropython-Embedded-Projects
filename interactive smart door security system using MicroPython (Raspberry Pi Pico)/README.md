It uses a keyboard for input; if the entered input matches the preset password, the display indicates the password is correct and the servo opens the door, whereas if the input does not match, the display indicates the password is incorrect and the servo does not operate.

component : 
1. Keypad 4x4 
2. Servo 
3. LCD
